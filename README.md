# kr5-react-shop

Учебный React-проект интернет-магазина (практика №19, КР №5).

## Стек

- React 18+
- Vite
- JavaScript (JSX)
- Функциональные компоненты

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173/

## Структура

```
src/
├── components/
│   ├── Header.jsx       — шапка сайта
│   ├── ProductCard.jsx  — карточка одного товара
│   └── ProductList.jsx  — сетка товаров (map + key)
├── data/
│   └── products.js      — учебный массив товаров
├── App.jsx              — корневой компонент
├── App.css
├── index.css
└── main.jsx             — точка входа
```

## Что реализовано

- [x] Проект создан через Vite
- [x] Очищен демо-шаблон
- [x] Компоненты Header, ProductCard, ProductList
- [x] Передача данных через props
- [x] Вывод списка через `map()`
- [x] `key={product.id}` при рендере списка
- [x] Безопасный вывод данных через `{...}` (без `dangerouslySetInnerHTML`)
- [x] Базовые стили

## Не реализовано (следующие практики)

- Поиск, фильтрация, сортировка (useState — практика №20)
- useEffect, controlled-форма, localStorage (практика №21)
- Маршрутизация, API-слой

## Связь с КР №4

Предметная область перенесена из `kr4-js-shop` (чистый JS + DOM) в компонентную архитектуру React.
